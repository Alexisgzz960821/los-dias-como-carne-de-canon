# Los Días Como Carne de Cañón

Sitio web de investigación, archivo y acción cultural sobre la precarización laboral, la energía del cuerpo y la memoria obrera en Nuevo León.

## Cómo ver el sitio

Abre `index.html` en tu navegador o sirve la carpeta localmente:

```bash
python3 -m http.server 8000
```

Luego visita:

```text
http://localhost:8000
```

## Estructura

- `index.html` — landing/home feed del proyecto
- `nosotrxs.html` — proyecto y equipo
- `ejes.html` — líneas de acción
- `archivo.html` — menú del archivo
- `galeria.html` — catálogo visual
- `calendario.html` — agenda
- `participa.html` — participación y colaboraciones
- `styles.css` — sistema visual unificado
- `js/` — datos y comportamiento de galería / agenda
